# Reports (__GAME__)

Read-only scouts leave their findings here, so the producer reads a file
instead of a long chat message.

- One file per scout, named `<topic>.md` (for example `story.md`, `art.md`).
- Scouts write only to this folder. The producer reads from it.
- Each report starts with these headings, in this order:

```
# <topic>

## Question
## Answer in three lines
## Details
## Sources or files read
## Open questions for the producer to bring to the director
```

Re-running a scout on the same topic replaces its file.
